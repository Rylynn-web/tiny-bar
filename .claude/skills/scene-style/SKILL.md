# 小酒馆场景风格规则

C4D 微缩模型质感：圆角、哑光、柔和阴影、低饱和暖色。所有数值放 `src/config/sceneConfig.ts`，组件里不写死。

## 材质
- **默认哑光**：`roughness ≥ 0.7`，`metalness = 0`。统一走 `Matte` 组件。
- **金属白名单**：只有不锈钢、镀铬、黄铜可以用金属材质，且只用于——灯具、吧凳、桌腿、花盆、摇酒壶/量杯、水龙头、门把、沙发管框、**镜子**。参数 `metalness = 1`，`roughness 0.3–0.45`，统一走 `Metal` 组件，具体值在 config。
- **镜子**是唯一的例外：`Metal finish="mirror"`，粗糙度约 0.05（`metal.mirrorRoughness`），反射的是只渲染一次的环境柔光板。**不做实时反射**（不用 CubeCamera / MeshReflectorMaterial）。
- **金属必须有环境反射**，否则发黑：用 drei `Environment` + 程序化 `Lightformer` 柔光板，只渲染一次（`frames={1}`），不下载 HDR。
- **玻璃 / 亚克力**：不用 `transmission`（太贵），用 `transparent` + `opacity` 的半透明标准材质，`depthWrite={false}`。

## 颜色
- 所有颜色从 `sceneConfig.palette` 取，组件里不出现色值。
- 新颜色先加进调色板并列给用户确认，再使用。
- Bar Buddy 保持黑白，不受场景调色板影响（`sceneConfig.buddy`）。
- **两层颜色**：家具、墙面、地面用低饱和的基础色；调色板里 `accent*` 开头的饱和强调色（钴蓝、橘红、草绿、柠檬黄、粉、青蓝）**只用在装饰品上**（画作、墙上的圆盘、相框、小摆件、花、壁灯），而且**面积要小**。大面积留白，靠几件饱和色的小物件提神。
- 强调色池在 `sceneConfig.decor.accents`，画作的"换配色"只从这里重新组合。

## 物件与布局
- 每个可摆放的物件都是 `src/scene/catalog.ts` 里的一项：组件只画**局部坐标**（原点在物件底面中心，+Z 为正面；墙面物件原点在墙面上，+Z 朝室内），摆放位置和朝向只写在 `src/config/layout.json`。
- 尺寸参数仍放 `sceneConfig`，但不要再在 config 里写物件的世界坐标。
- 同一类型的变体（颜色、放什么）用 layout 的 `props`，颜色写调色板键名。
- 可坐的家具把座位锚点挂在组件的静态属性 `seats` 上（相对家具的位置和朝向），座位由 `seatConfig.deriveSeats` 自动推导。
- 新物件先在 `?edit` 编辑器里摆好再保存，不要手算坐标。

## 造型
- 方块一律用 `BevelBox`，圆形物件用 `RoundedCylinder` 或旋转体，倒角来自统一参数。例外：厚度 ≤ 2cm 的小薄片（书、杂志、卡扣）用普通方块，倒角看不出来，省面数。
- 倒角分三档：大件家具 / 小件 / 细杆，档位值在 config。
- 复杂轮廓（L 形吧台、斜角地面、壳形椅）用 `Shape` + `ExtrudeGeometry`（带 bevel）或 `LatheGeometry`。
- 同一种家具的多个实例共用同一套几何体与材质（模块级缓存或 `useMemo`），只换颜色。

## 贴图（CanvasTexture）
- 只画**原创抽象图形**，不照搬参考图，不出现任何 logo 或文字。
- 边长 ≤ 512，启动时生成一次并缓存，`colorSpace = SRGBColorSpace`。
- **画作例外**：墙上的画（`src/scene/decor/`）高画质档长边 1024，手机 / 低画质档 512（`decor.textureSize`）。
- 配色从调色板取。
- 画作由种子生成：`props.seed` 决定构图，`props.paletteSeed` 决定从强调色里抽哪几种；同样的参数只画一次（按 类型 + 种子 + 配色 + 尺寸 缓存）。编辑器里"换一幅 / 换配色"只是换种子，满意的种子随 layout.json 保存。

## 墙面装饰
- 都是墙面物件（`mount: 'wall'`），原点在墙面上、画面中心高度；跟随所在的墙一起隐藏（左右墙背对摄像机时）。
- 画布有一点厚度和圆角，离墙一条缝（`decor.canvas.wallGap`），让环境光遮蔽在边缘压出淡阴影；画面是贴在正面的哑光平面。
- 书和杂志封面只用三组颜色：米色系 / 黑白 / 深蓝（`decor.bookLedge.coverGroups`），按顺序轮换，没有文字。
- 发光装饰（壁灯）走 `Glow` 分组，墙上的光晕用叠加混合的径向渐变平面，不加真实光源。

## 光照
- **只有一盏投影光**（主平行光），**只在白天开**：从右侧落地窗外斜照进来（`lighting.sunPosition`），地面和左墙上落下窗形阳光。夜晚 `sunIntensity = 0`，整盏关掉、不算阴影，屋里只靠暖色环境光和灯具。其余灯具、蜡烛、灯带用**自发光 + Bloom**。
- 白天要有晴天感：主光暖白偏强、影子边缘清楚，环境光天空一侧偏冷；夜晚环境光和背景整体偏暖（琥珀 / 焦糖）。
- 吊灯、落地灯这类有灯罩的灯，灯下用 `LightCone`（叠加混合的假体积光，顶部亮、往下淡、侧边柔）+ `LightPool` 光斑，不加真实光源。着色器里 `pow` / `normalize` 的输入要夹在安全范围，NaN 经过后处理会让整屏变黑。
- 自发光按灯具分组（`sceneConfig.emissive`：吊灯、落地灯、蘑菇灯、叠环灯、壁灯、灯带、屏幕，以及各自的光斑 / 光锥浓度），每件灯还有 `props.brightness` 单件倍数（编辑器「亮度」滑杆）。
- Bloom 阈值设在 3（`sceneConfig.bloom.luminanceThreshold`）：被主光照亮的浅色表面在 HDR 里能到 2.5 左右，阈值低了会被误判成发光。自发光物件的最终亮度要高于阈值才会有光晕。用 `mipmapBlur`。
- 自发光强度按物件分组放 config，白天几乎关闭，夜晚打开。
- 需要补光时最多 2 盏不投影的点光源，默认不开。
- 灯具在桌面/台面上的光感用 `LightPool`（叠加混合的径向渐变假光斑），不用真实光源。
- 自发光物件要放在从默认俯视角看得见的位置（灯罩下的灯泡、出檐下的灯带会被挡住，看不到光晕）。

## 实例化与预算
- 同一几何体出现 ≥ 8 次就用 `InstancedMesh`（`InstancedMatte`），颜色用 instanceColor。
- 几何细分按倒角档位分级（`sceneConfig.detail`）：小件和细杆少分段；瓶子杯子等小旋转体用 `smallLatheSegments`。大面积的圆形（地毯）单独指定高分段，避免露出多边形。
- 全场景目标：draw calls ≤ 150，三角面 ≤ 15 万。每批搭完测量一次。
- 每个物件外面包着 `MergeStatic`：同一物件里材质参数相同的哑光 / 金属零件，**颜色不同也会合并**（颜色写进顶点颜色，合并后用白色 + `vertexColors` 的材质）。自发光零件按颜色分组；半透明、带顶点色、实例化、标了 `userData.noMerge` 的不合并。需要单独动的零件标 `noMerge`。
- 只投影不显示的物体（隐形投影墙）放在 `shadows.shadowOnlyLayer`：主相机不画，只有主光的阴影相机画。
- 测量方法：关掉阴影贴图更新后 `gl.render` 一次读 `gl.info.render.calls`，只算主画面。
- 外部模型（只限植物，椅子备选）每个 ≤ 300KB，用 drei `useGLTF` 加载；下载前向用户确认文件名、来源、大小。
- 外部模型只用几何形状：材质和贴图在加载后全部替换成调色板里的哑光颜色（植物见 `plantGeometry.ts`：按原颜色把三角面分成浅叶 / 深叶 / 茎干）。
- 加载后自动缩放到 config 里的目标高度、根部对齐原点，模型文件缺失时不显示也不报错（错误边界）。
- 每个外部模型都要写进 `public/models/CREDITS.md`（名称、作者、授权、链接）；CC-BY 必须署名。只接受 CC0 / CC-BY，不要 NC、ND。

## 窗外景观
- 不用天空盒、不建模城市：天空 + 多层剪影平面，每帧把窗洞沿当前视线投影到各层深度，正好铺满窗口（不会露边，也不会有大平面露到墙外）。
- 剪影贴图是数据贴图（R 楼体 / G 每栋楼随机值 / B 能否开窗），窗户在着色器里按世界坐标格子生成；昼夜用同一组贴图在着色器里切换。
- 正交相机下真实视差过大，各层只保留一部分（`cityView.layers[].parallax`）。
- 窗外分层在编辑器里不参与点击和包围盒（`userData.editorIgnore`）。

## 小人
- 最多 8 个，坐在座位上（`src/state/guests.ts` 记每个座位的状态、饮料、随机种子）。保持黑白，不用调色板。
- 每个小人是一组**不显示的层级节点**（`character/rig.ts`：身体 → 头 / 手臂，髋 → 腿），姿势靠旋转节点来摆，不用骨骼绑定；每帧把节点的世界矩阵写进**所有小人共用的实例化网格**（`character/Guests.tsx`），每种零件 / 道具一次绘制。
- 姿势和动作节奏全部放在 `src/config/poses.ts`（状态 × 座位类型）；状态切换用指数平滑（约 400ms），道具出现带回弹。每人自己的种子错开呼吸、眨眼和小动作。
- 道具（杯子、书、笔记本、"…"气泡）共享几何体和材质；放在桌上时读座位的桌面锚点（`seat.desk`，由家具的 `surfaces` 推导），没有桌面就放腿上 / 拿在手里。
- 表情只靠眼睛：眼睛是贴在头部正面的曲面贴片，所有表情画在一张图集里（`character/faceAtlas.ts`），每个实例只改格子偏移；腮红是另一片（只有 happy / squint 显示），眨眼只压扁眼睛那一片。切换表情先快速闭眼再换。自动规则在 `src/config/expressions.ts`，手动表情走 `src/net/RoomClient.ts` 的 `setEmote`。腮红 `#F4A6B4` 是小人身上唯一的颜色。
- 同屏 8 人时细分按 `buddy.detail` 取低一档，全场景仍要在 150 次绘制 / 15 万三角面以内。

## 影子
- 开口的薄壳物件（灯罩、杯子、花瓶、碗）必须 `shadowSide = DoubleSide`，否则只有背光那半边投影，会出现月牙形影子。
- 小物件（杯子、瓶子、书、浆果）不投影只接收，省阴影贴图开销。

## 手机
- 任何视觉改动都要考虑手机性能：后处理开销、DPR 上限 1.5、阴影贴图 1024。
